# Rehla_Wa3y
🌟 Awareness Journey is an interactive website that teaches middle school students safe online behavior and provides support resources.

##  Website Goals:

- Educate students about:
  - Cyber extortion
  - Cyberbullying
  - Online harassment
  - Digital addiction
  - Self-esteem issues caused by online comparisons
- Teach students to make safe decisions through interactive stories
- Provide instant feedback and analysis for the choices made
- Offer real helpline numbers in Egypt for emergency support

---

##  Features:

- Simple and user-friendly interface
- Interactive stories with multiple-choice options
- Immediate analysis of user decisions
- Fully responsive design for mobile, tablet, and desktop
- Real helpline numbers displayed on the final page

---

## 📞 Helpline Numbers in Egypt:

- **Cyber Extortion:**
  - Egyptian Police: 122
  - Child Protection Hotline: 108
- **Bullying:**
  - Child Protection Hotline: 108
- **Harassment:**
  - Egyptian Police: 122
  - National Council for Women: 15115

> All calls are confidential – asking for help is bravery, not weakness.

---

## Technologies Used:

- HTML5
- CSS3 (with Responsive Design)
- JavaScript (for interactive stories and analysis)
- Google Fonts (Cairo)

---

## 🚀 How to Use:

1. Open `index.html` in any modern browser.
2. Enter the student's first and last name.
3. Start the interactive journey immediately.
4. Follow the story instructions and make safe choices.
5. After finishing, the website will show the analysis and official helpline numbers.
